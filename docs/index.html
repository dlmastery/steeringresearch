Steering Autoresearch

An autonomous, pre-registered research program on activation steering of small language models — run on a single laptop GPU.

Read this page before the dashboard. Most numbers in this repository are a screening-tier search trail, not results. Exactly one finding currently clears the statistical bar. This page says which, why the rest can't be ranked, and where to look.

1. The one result that clears the bar

Evaluation-tier · judge-free

Norm preservation is the worst way to spend a steering budget

Steering pushes a model's hidden state a certain distance. That distance can be spent on radius (ordinary addition, which changes the vector's length) or on angle (norm-preserving rotation, which does not). Recent work assumes preserving the norm protects output quality. Measured at equal displacement, the opposite holds.

quantityvalue
Extra perplexity cost of rotation vs. addition+91.24
Bootstrap 95% CI[87.98, 94.71]
Resamples in which the ordering held8 / 8
Same test with a norm-matched random direction+16.80
Power checkn=8, min p = 0.0078, power ≈ 1.00

The random-direction control is what makes this stand up: a meaningless vector of identical length shows almost no rotation penalty, so the cost is tied to rotating along a meaningful direction — not to turning vectors in general.

Why it matters. GEMS (arXiv:2606.19946), ORBIT (2606.22357) and Selective Steering (2601.19375) all build on norm preservation. Selective Steering dismisses additive steering as causing “catastrophic degradation on smaller models” — but never holds displacement fixed. This supplies the missing control, and inverts the conclusion at ≤4B.

2. Two caveats that invalidate a naive reading

Instrument failure

The judge is unreliable, so judge-based claims are suspended

Many experiments score model output with a local LLM judge. Calibrated against ground-truth labels, that judge reaches ROC-AUC 0.665 — and 0.751 with an improved continuous readout. Both sit below this project's own 0.85 gate, and a newer, larger judge did not help, so the weakness belongs to the task rather than the model version.

Consequence: neither an efficacy claim nor a null may rest on it — at that accuracy the instrument cannot resolve the effect sizes involved. Live work therefore uses judge-free endpoints: perplexity, geometry, and probe AUC against real labels.

Not one scale

The 124 legacy rows cannot be ranked against each other

The scoring formula was edited after those rows were written, so their stored scores came from a formula that no longer exists — 92 of 124 do not reproduce. Two of the five scored axes were also inert (constant), and the stored “champion” was a single-seed row with stubbed safety scoring that never advanced across the 121 experiments that followed it.

Sorting that table is meaningless. It is kept as history, not as a leaderboard.

4. What this program does differently

Its previous incarnation ran 124 experiments and produced zero external-ready findings. A forensic audit established why, and each cause became a rule the program is now bound by:

what went wrongrule now enforced
Everything measured with an uncalibrated judgeValidate the instrument before trusting it
74% of runs on a model too small to show the effectNever run where the effect cannot appear
91% single-seed; the champion never advancedA screening run is not a result
0 of 124 falsifiable numeric predictionsPredictions are pre-registered and machine-checked
The rigor rule was arithmetically impossible*Feasibility is computed per family, before the run

* The old contract demanded n ≥ 7 seeds and Holm correction. At n = 7 the smallest attainable p-value is 0.0156, while Holm's threshold for a family of 4 is 0.0125 — so it could not be satisfied at any effect size. It was met zero times in 124 experiments. The harness now refuses under-powered designs up front.

Internal QA pass — implementer and critic share a model family; independent external review pending. Adversarial reviews in this repository are simulated internal red-teaming and are never external validation or a venue decision.
